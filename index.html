CodeNav privacy policy

Effective 7 October 2026. Applies to the CodeNav for GitLab & GitHub browser extension.

CodeNav adds IDE-style code navigation (file explorer, tabs, go to definition, find references, symbol search) to GitLab and GitHub pages. It runs entirely in your browser. This policy explains what it reads, what it stores, and where data goes.

  • CodeNav reads code only from the GitLab or GitHub site you are browsing, through that site's own API, using your existing session or a token you give it.
  • Parsed indexes and source files are cached locally in your browser. Non-code files are never written to disk.
  • Tokens stay in the extension's storage and are sent only to the host they belong to.
  • There is no analytics and no telemetry. Nothing is sent to the developer or to any third party, and nothing is sold.
  • You can clear the cache at any time from the extension's Options page.

What CodeNav reads

When you open CodeNav on a repository page, it requests that repository's file list and the contents of files from the same site:

  • GitLab (gitlab.com or a self-hosted GitLab you enable): requests go to the GitLab host of the current tab, to its API endpoints (/api/v4, /api/graphql and the file-finder JSON). They are made from the page itself, so they use your existing GitLab sign-in. If you add a GitLab personal access token in Options, it is used instead and sent only to that GitLab host.
  • GitHub (github.com): requests go to api.github.com and raw.githubusercontent.com. Public repositories work without signing in. Cookies are never sent.
  • GitHub Enterprise Server (a host you enable): requests go to that host's /api endpoints with the personal access token you provide.

CodeNav may also open other repositories on the same site when you navigate into them, for example a Go module or a Git submodule that the current repository depends on.

Signing in with GitHub

"Sign in with GitHub" uses GitHub's OAuth device flow. CodeNav asks github.com for a one-time code, you enter that code on github.com, and GitHub returns an access token. No password and no client secret are involved. CodeNav then asks api.github.com for your account name so it can show who you are signed in as.

What CodeNav stores, and where

All of it stays in your browser profile:

  • Settings (in the extension's storage): the hosts you enabled, per-project configuration, editor font size, and any tokens: a GitLab or GitHub Enterprise personal access token you entered, or the GitHub token and account name from "Sign in with GitHub".
  • Cache (in the extension's IndexedDB): repository file listings, commit identifiers, parsed symbol indexes, and the contents of source-code files, so that navigation is fast the next time. Other files, such as configuration files that might contain secrets, are kept in memory only while CodeNav is open and are never written to the cache.

Where data goes

  • Tokens are sent only to their own host: a GitLab token only to that GitLab host, the GitHub token only to GitHub's API (never to raw.githubusercontent.com), a GitHub Enterprise token only to that Enterprise host.
  • CodeNav has no server. It does not send code, browsing activity, identifiers, usage statistics or any other data to the developer or to any third party. It contains no analytics, telemetry, advertising or tracking code, and it does not load code from the internet.
  • Your data is not sold, shared, or used for any purpose other than code navigation.
  • Some symbols from libraries outside the repository show a documentation link (for example to the Go, Python or MDN reference). Those pages open only if you click the link, like any other link.

Your choices

  • Clear the cache: Options → Clear cache deletes everything CodeNav has cached.
  • Remove a token: Options → Sign out (GitHub) or clear the token field for a host. To revoke the GitHub authorization itself, use GitHub → Settings → Applications.
  • Remove access to a site: remove the host in Options, or revoke the site permission in your browser's extension settings.
  • Uninstall: removing the extension deletes its settings, tokens and cache.

Children

CodeNav is a developer tool and is not directed at children.
